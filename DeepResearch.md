* **Ratto等 (2023)** – 采用ONNXParser将ONNX模型转换成可执行C代码 ([Table 1 | An Automated Design Flow for Adaptive Neural Network Hardware Accelerators | Journal of Signal Processing Systems
  ](https://link.springer.com/article/10.1007/s11265-023-01855-x/tables/1#:~:text=A1))。用户可手动调优代码（插入流水线缓冲、设置HLS指令等），然后用Vivado HLS将C++函数编译成硬件模块库 ([An Automated Design Flow for Adaptive Neural Network Hardware Accelerators | Journal of Signal Processing Systems
  ](https://link.springer.com/article/10.1007/s11265-023-01855-x#:~:text=The%20next%20step%20is%20to,step%20A2))。另一条路径中，ONNX模型被转换成多数据流（Dataflow）网络描述（XML格式），由MDC合并多个数据流模型生成最终的可重构硬件加速器 ([Table 1 | An Automated Design Flow for Adaptive Neural Network Hardware Accelerators | Journal of Signal Processing Systems
  ](https://link.springer.com/article/10.1007/s11265-023-01855-x/tables/1#:~:text=MDC)) ([An Automated Design Flow for Adaptive Neural Network Hardware Accelerators | Journal of Signal Processing Systems
  ](https://link.springer.com/article/10.1007/s11265-023-01855-x#:~:text=3.1%20CNN%20Modelling%20,Input))。图下所示为该流程示意 ([[2406.09078] ONNX-to-Hardware Design Flow for Adaptive Neural-Network Inference on FPGAs](https://ar5iv.org/pdf/2406.09078))：ONNXParser读取模型，HLS Writer生成层C++实现和TCL脚本，Vivado HLS合成出模块库，MDC将模块和网络拓扑组合成完整的FPGA加速器 ([Table 1 | An Automated Design Flow for Adaptive Neural Network Hardware Accelerators | Journal of Signal Processing Systems
  ](https://link.springer.com/article/10.1007/s11265-023-01855-x/tables/1#:~:text=A1))。
  * **输入** ：标准ONNX格式的CNN模型（本文采用改写后的Inception v2结构 ([An Automated Design Flow for Adaptive Neural Network Hardware Accelerators | Journal of Signal Processing Systems
     ](https://link.springer.com/article/10.1007/s11265-023-01855-x#:~:text=The%20overall%20structure%20of%20the,momentum%20defined%20by%20default%20in))）。模型输入为浮点张量（如[NCHW]格式） ([An Automated Design Flow for Adaptive Neural Network Hardware Accelerators | Journal of Signal Processing Systems
     ](https://link.springer.com/article/10.1007/s11265-023-01855-x#:~:text=The%20overall%20structure%20of%20the,momentum%20defined%20by%20default%20in))。
  * **输出** ：多数据流可重构FPGA推理加速器的RTL代码（Verilog），以及对应的FPGA系统集成脚本和IP核 ([Table 1 | An Automated Design Flow for Adaptive Neural Network Hardware Accelerators | Journal of Signal Processing Systems
     ](https://link.springer.com/article/10.1007/s11265-023-01855-x/tables/1#:~:text=MDC))。
  * **工具链** ：ONNXparser (Aloha框架) ([[2406.09078] ONNX-to-Hardware Design Flow for Adaptive Neural-Network Inference on FPGAs](https://ar5iv.org/pdf/2406.09078#:~:text=))将ONNX→C模型；Vivado HLS 将C模型→RTL；Multi-Dataflow Composer (MDC) 将HDL模块和数据流拓扑合成最终硬件 ([[2406.09078] ONNX-to-Hardware Design Flow for Adaptive Neural-Network Inference on FPGAs](https://ar5iv.org/pdf/2406.09078#:~:text=The%20Multi,taken%20from%20the%20HDL%20library)) ([Table 1 | An Automated Design Flow for Adaptive Neural Network Hardware Accelerators | Journal of Signal Processing Systems
     ](https://link.springer.com/article/10.1007/s11265-023-01855-x/tables/1#:~:text=A3))。
  * **关键技术** ：利用流水线处理，将卷积拆分为LineBuffer和Convolution两个Actor ([An Automated Design Flow for Adaptive Neural Network Hardware Accelerators | Journal of Signal Processing Systems
     ](https://link.springer.com/article/10.1007/s11265-023-01855-x#:~:text=A%20great%20deal%20of%20effort,see%20Listing))；支持动态可重构（N1/N2步骤）以实现不同数据流的硬件版本 ([An Automated Design Flow for Adaptive Neural Network Hardware Accelerators | Journal of Signal Processing Systems
     ](https://link.springer.com/article/10.1007/s11265-023-01855-x#:~:text=The%20possible%20implementations%20of%20two,and%20LAYER_D%20with%20double)) ([An Automated Design Flow for Adaptive Neural Network Hardware Accelerators | Journal of Signal Processing Systems
     ](https://link.springer.com/article/10.1007/s11265-023-01855-x#:~:text=two%20steps%20that%20are%20manual,constitutes%2C%20together%20with%20the%20input))；允许用户通过ONNX模型或中间数据流图手动设计适应性点 ([Table 1 | An Automated Design Flow for Adaptive Neural Network Hardware Accelerators | Journal of Signal Processing Systems
     ](https://link.springer.com/article/10.1007/s11265-023-01855-x/tables/1#:~:text=A2)) ([Table 1 | An Automated Design Flow for Adaptive Neural Network Hardware Accelerators | Journal of Signal Processing Systems
     ](https://link.springer.com/article/10.1007/s11265-023-01855-x/tables/1#:~:text=N1))。
* **Manca等 (2024)** – 针对量化神经网路，整个ONNX→硬件流程实现自动化 ([[2406.09078] ONNX-to-Hardware Design Flow for Adaptive Neural-Network Inference on FPGAs](https://ar5iv.org/pdf/2406.09078#:~:text=The%20proposed%20design%20flow%20automates,2)) ([[2406.09078] ONNX-to-Hardware Design Flow for Adaptive Neural-Network Inference on FPGAs](https://ar5iv.org/pdf/2406.09078#:~:text=))。输入采用扩展的QONNX格式（可指定任意精度量化） ([[2406.09078] ONNX-to-Hardware Design Flow for Adaptive Neural-Network Inference on FPGAs](https://ar5iv.org/pdf/2406.09078#:~:text=The%20proposed%20design%20flow%20automates,37%20and))，ONNXParser (带HLS Writer)将模型拓扑和量化信息读入，生成C++层实现和Vivado HLS综合脚本 ([[2406.09078] ONNX-to-Hardware Design Flow for Adaptive Neural-Network Inference on FPGAs](https://ar5iv.org/pdf/2406.09078#:~:text=The%20QONNX%20file%20serves%20as,dependent%20files))。Vivado HLS编译后得到片上硬件模块库；Multi-Dataflow Composer(MDC)使用生成的网络拓扑XML和CAL文件，将HDL库合成最终Streaming加速器 ([[2406.09078] ONNX-to-Hardware Design Flow for Adaptive Neural-Network Inference on FPGAs](https://ar5iv.org/pdf/2406.09078#:~:text=Figure%202%3A%20On%20the%20left%2C,architecture%20for%20a%20convolutional%20layer))。该流程如图示，包括演员流路径和网络流路径，可选择生成单一或多解算器（支持近似计算） ([[2406.09078] ONNX-to-Hardware Design Flow for Adaptive Neural-Network Inference on FPGAs](https://ar5iv.org/pdf/2406.09078#:~:text=The%20proposed%20flow%2C%20as%20depicted,approximate%20solutions))。
  * **输入** ：量化的ONNX模型（QONNX格式），包含每层的精度、量化比例等信息 ([[2406.09078] ONNX-to-Hardware Design Flow for Adaptive Neural-Network Inference on FPGAs](https://ar5iv.org/pdf/2406.09078#:~:text=The%20proposed%20design%20flow%20automates,2))。
  * **输出** ：在FPGA上运行的流式神经网络推理加速器的RTL实现（Verilog），可实现多数据流复用和运行时调整 ([[2406.09078] ONNX-to-Hardware Design Flow for Adaptive Neural-Network Inference on FPGAs](https://ar5iv.org/pdf/2406.09078#:~:text=The%20proposed%20flow%2C%20as%20depicted,approximate%20solutions))。
  * **工具链** ：改进的ONNXParser（含HLS Writer） ([[2406.09078] ONNX-to-Hardware Design Flow for Adaptive Neural-Network Inference on FPGAs](https://ar5iv.org/pdf/2406.09078#:~:text=))；Vitis HLS将C++函数综合为RTL ([[2406.09078] ONNX-to-Hardware Design Flow for Adaptive Neural-Network Inference on FPGAs](https://ar5iv.org/pdf/2406.09078#:~:text=The%20Vitis%20HLS%20tool%5E%7B6%7D%5E%7B6%7D6%20https%3A%2F%2Fwww.AMD.com%2Fsupport%2Fdocumentation,the%20insertion%20of%20directives%20in))；MDC工具合并数据流描述与模块库生成最终硬件 ([[2406.09078] ONNX-to-Hardware Design Flow for Adaptive Neural-Network Inference on FPGAs](https://ar5iv.org/pdf/2406.09078#:~:text=The%20Multi,taken%20from%20the%20HDL%20library))。
  * **关键流程** ：模型先转换为QONNX，ONNXParser读取QONNX生成层级C++实现；插入Line Buffer等优化使代码可综合 ([An Automated Design Flow for Adaptive Neural Network Hardware Accelerators | Journal of Signal Processing Systems
     ](https://link.springer.com/article/10.1007/s11265-023-01855-x#:~:text=A%20great%20deal%20of%20effort,see%20Listing))；Vivado HLS生成Actor库；MDC用生成的拓扑和Actor接口(.xml/.cal)自动拼装硬件系统 ([[2406.09078] ONNX-to-Hardware Design Flow for Adaptive Neural-Network Inference on FPGAs](https://ar5iv.org/pdf/2406.09078#:~:text=Figure%202%3A%20On%20the%20left%2C,architecture%20for%20a%20convolutional%20layer))。
* **Fahim等 (2021)** – hls4ml框架支持将训练好的神经网络（Keras/TensorFlow/PyTorch/ONNX）转换为FPGA/ASIC可综合代码 ([hls4ml: An Open-Source Codesign Workflow to Empower Scientific Low-Power Machine Learning Devices](https://par.nsf.gov/servlets/purl/10300178#:~:text=user,this%20step%2C%20for%20example%2C%20batch))。用户首先导出模型为ONNX格式 ([hls4ml: An Open-Source Codesign Workflow to Empower Scientific Low-Power Machine Learning Devices](https://par.nsf.gov/servlets/purl/10300178#:~:text=user,this%20step%2C%20for%20example%2C%20batch))，hls4ml将其转换为内部中间表示并做图优化（如融合BatchNorm） ([hls4ml: An Open-Source Codesign Workflow to Empower Scientific Low-Power Machine Learning Devices](https://par.nsf.gov/servlets/purl/10300178#:~:text=user,this%20step%2C%20for%20example%2C%20batch)) ([hls4ml: An Open-Source Codesign Workflow to Empower Scientific Low-Power Machine Learning Devices](https://par.nsf.gov/servlets/purl/10300178#:~:text=A%20suite%20of%20optimizers%20then,These))。生成阶段将网络映射到预定义的HLS代码模板库中，输出可综合的C/C++文件。用户在Python环境中可以对生成的模型进行位精度仿真验证 ([hls4ml: An Open-Source Codesign Workflow to Empower Scientific Low-Power Machine Learning Devices](https://par.nsf.gov/servlets/purl/10300178#:~:text=the%20precision%20by%20truncating%20small,familiar%20to%20ML%20developers%2C%20where))，然后调用Vivado HLS等工具综合成FPGA IP核 ([hls4ml: An Open-Source Codesign Workflow to Empower Scientific Low-Power Machine Learning Devices](https://par.nsf.gov/servlets/purl/10300178#:~:text=quantized%20models,is%20for%20Xilinx%20Vivado%20HLS))。
  * **输入** ：ONNX或其他主流框架导出的神经网络模型，可包含量化信息 ([hls4ml: An Open-Source Codesign Workflow to Empower Scientific Low-Power Machine Learning Devices](https://par.nsf.gov/servlets/purl/10300178#:~:text=user,this%20step%2C%20for%20example%2C%20batch))。hls4ml会附加用户配置（层并行度、位宽等）进行转换。
  * **输出** ：生成可综合的HLS C++源代码（含各层算子实现），最终经Vivado HLS合成得到FPGA上的硬件IP核 ([hls4ml: An Open-Source Codesign Workflow to Empower Scientific Low-Power Machine Learning Devices](https://par.nsf.gov/servlets/purl/10300178#:~:text=quantized%20models,is%20for%20Xilinx%20Vivado%20HLS))。用户可获取比对软件输出的仿真结果以验证功能 ([hls4ml: An Open-Source Codesign Workflow to Empower Scientific Low-Power Machine Learning Devices](https://par.nsf.gov/servlets/purl/10300178#:~:text=quantized%20models,is%20for%20Xilinx%20Vivado%20HLS))。
  * **工具链** ：hls4ml Python包（提供转换器、图优化、代码生成） ([hls4ml: An Open-Source Codesign Workflow to Empower Scientific Low-Power Machine Learning Devices](https://par.nsf.gov/servlets/purl/10300178#:~:text=user,this%20step%2C%20for%20example%2C%20batch))；后端调用Xilinx Vivado HLS（或Intel HLS、Catapult HLS） ([hls4ml: An Open-Source Codesign Workflow to Empower Scientific Low-Power Machine Learning Devices](https://par.nsf.gov/servlets/purl/10300178#:~:text=quantized%20models,is%20for%20Xilinx%20Vivado%20HLS))。
  * **架构特点** ：支持极低精度量化（二值、四值等） ([hls4ml: An Open-Source Codesign Workflow to Empower Scientific Low-Power Machine Learning Devices](https://par.nsf.gov/servlets/purl/10300178#:~:text=Several%20recent%20results%20highlight%20the,The%20customized%20design))、可配置的并行度、可调流水深度等；用户可在Python环境中对每层位宽进行性能分析 ([hls4ml: An Open-Source Codesign Workflow to Empower Scientific Low-Power Machine Learning Devices](https://par.nsf.gov/servlets/purl/10300178#:~:text=Figure%203%20shows%20an%20example,the%20boxes))，调优完成后输出硬件实现 ([hls4ml: An Open-Source Codesign Workflow to Empower Scientific Low-Power Machine Learning Devices](https://par.nsf.gov/servlets/purl/10300178#:~:text=quantized%20models,is%20for%20Xilinx%20Vivado%20HLS))。
* **Biggs等 (2025)** – 针对带“早退”(Early-Exit)机制的神经网络，提出自动化FPGA部署工具链ATHEENA。用户用PyTorch构造Early-Exit模型并导出为ONNX。ATHEENA将ONNX中条件控制流转化为硬件可执行形式，并结合fpgaConvNet工具生成HLS代码。编译流程包括模型剖析、fpgaConvNet优化、Vivado HLS综合以及Vivado集成生成最终比特流和主机驱动代码。
  * **输入** ：带Early-Exit分支的ONNX网络模型（支持条件计算层，如Softmax、If等）。
  * **输出** ：多核心FPGA推理设计的比特流及对应主机应用代码，可实现按样本复杂度提前退出加速推理。
  * **工具链** ：ATHEENA工具（ONNX解析扩展）；基于fpgaConvNet的HLS代码生成器和IP整合器；Xilinx Vivado HLS和Vivado IP Integrator完成综合和系统集成。
  * **关键流程** ：使用PyTorch脚本保存条件控制，将模型转为ONNX并验证；扩展fpgaConvNet解析器支持Early-Exit操作（Softmax、比较、If等）；fpgaConvNet生成HLS模板代码，各核经Vivado综合，Vivado IP Integrator生成最终FPGA加速器。
* **Cooper (2023)** – 提出“Bespoke”编译器，将8位量化神经网路从ONNX规格直接编译为FPGA流水计算模块。该工具首先解析ONNX文件生成中间图，迭代节点建立带FIFO的模块网络。然后根据FPGA资源（DSP/BRAM）进行分配：将权重导出为BRAM初始化（.mem文件），动态调整乘法器并行度，分配寄存器平衡各路径延迟。最后将各模块组装成完整SystemVerilog设计，并用Vivado综合。
  * **输入** ：ONNX格式的量化神经网络模型（Bespoke重点支持8位整数网络）。
  * **输出** ：以SystemVerilog表示的定制神经网络硬件，每层为流水线模块，适用于FPGA综合。
  * **工具链** ：自定义Python脚本（ONNX解析器）；编译器进行DSP/BRAM资源分配；Xilinx Vivado用于最终综合。
  * **关键流程** ：ONNX解析阶段构建数据流中间图；BRAM分配阶段将模型权重生成.mem文件；DSP分配阶段调整各层并行度和寄存器以匹配资源；代码生成阶段输出SystemVerilog，并在Vivado上生成FPGA位流。
